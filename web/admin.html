添加知识点

Import Knowledge Points

系统支持JSON文件导入，知识点的结构如下： 
{
  "subject_id": 1,
  "items": [
    {
      "title": "数与式",
      "level_type": "module",
      "parent_leveltype": "root",
      "parent_title": null,
      "content": "知识点内容",
      "alias": "english_alias"
    }
  ]
}
• title：节点标题（必填）
• level_type：节点级别（必填），可选 module/domain/subject_area/chapter/unit/section/concept/lesson/knowledge_point
• parent_leveltype：父节点的 level_type（顶级为 null）
• parent_title：父节点标题（用于精确匹配父节点）
• content：知识点内容（可选）
• alias：英文别名（可选）
知识点的层级关系：
root：学科根节点（系统自动创建，无需导入）
module/domain/subject_area：模块节点；
chapter/unit：章节点；
section/concept/lesson：课节点；
knowledge_point：知识点；
导入流程：先导入模块/章节，再根据 parent_leveltype + parent_title 匹配父节点
