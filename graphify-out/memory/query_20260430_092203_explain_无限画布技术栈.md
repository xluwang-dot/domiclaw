# Q: Explain 无限画布技术栈

## Answer

无限画布使用 Vue 3 (CDN) + CSS transform(translate+scale) + SVG 边渲染 + DOM 绝对定位节点 + wheel/mousedown 事件处理。数据通过 REST GET /api/graph 加载，实时推送通过 SSE EventSource。节点位置由后端 buildGraphData() 用扇区布局算法计算。
